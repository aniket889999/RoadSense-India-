# Reference data

`in_rto_codes.json` — Indian RTO registration codes mapped to issuing office and
jurisdiction. Built by `scripts/build_rto_table.py` from Wikipedia, *List of Regional
Transport Office districts in India*, revision 1383694791 (2026-11-04).

It is a public directory of where codes are issued. It contains no vehicle, owner or
registration records. See `docs/anpr/format_check_v2_results.md`.
